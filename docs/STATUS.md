## Курс

С 2026-10-01 (#ENG-024) проект движется от RPG-симулятора к детерминированной
модульной основе для симуляций, которые строит ИИ; RPG стала эталонным миром.
Всё, что относится к этой основе (kernel, контракт модуля, уровни доверия, откат,
реестр модулей), пока **не реализовано**. Физического модуля **не существует**:
брейнштурм-заметки ошибочно называли его написанным. Вехи M0–M4 (сначала играбельный RPG, M0) и риски:
`vision/STRATEGY.md`. Правила: `GOLDEN_RULES.md`.

## Что работает

Рабочий вертикальный срез: Python 3.14 + Ollama + Gemma (сейчас `gemma4:e4b`),
`main.py`, многораундовый tool-calling loop, SQLite как источник истины.

- покупка предмета, апгрейд стата, проверка «игрок не может выдумать несуществующий
  предмет»;
- загрузка миров из `data/worlds/<n>/world.json` (`main.py --world <n>`),
  встроенные миры: `allizium`, `station_demo`;
- пресет календаря из `data/rules/presets/` (поле `rules_preset`);
- tool surface из одного слова и ≤1 аргумента (#ENG-028): `look`, `inspect`,
  `find`, `inventory`, `upgrade`, `wait`, `trade` и внутри торговли `stock`,
  `buy`, `end`; тулы фильтруются по локации и режиму;
- взаимодействие прерывает другие (#ENG-027): в торговле успешный `act`
  завершает её, политика режимов в `MODE_POLICY`;
- атомарные мутации через `Database.transaction()`, `ActionAPI.call()` не бросает
  исключений, тесты на pytest.
