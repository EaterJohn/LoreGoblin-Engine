# Генерация мира и материализация

Не просить генератор создать весь мир как один готовый объект. Строить допустимое
состояние из:

```text
seed + генераторы + свойства + ограничения + правила + детерминированная случайность
```

LLM могут участвовать, но авторитет остаётся за Engine.

## Роли

- **Генератор/LLM предлагает:** имена, раскладки, комбинации, описания, структуры,
  истории.
- **Engine проверяет:** ограничения, совместимость, ссылки, нужные ресурсы,
  согласованность состояния, правила. LLM не может обойти проверку.

## Слоями

- Макро: глобальные законы → ландшафт/климат → регионы → биомы → крупные ресурсы.
- Локально: регион → локации → структуры → объекты → аффордансы → начальное состояние.
- Цепочка из идей: seed → биом → регион → генератор локации → архетип → черты →
  аффордансы → ресурсы → начальное состояние → канон
  (`../ideas/AFFORDANCES_AND_PERSISTENCE_IDEA.md` §7).

## Архетип и экземпляр

Архетип даёт умолчания и ограничения, экземпляр хранит сгенерированное состояние
(материалы, размеры, состояние, история, положение). Из пространства свойств:
`wood + rigid + seatable + supports → возможный стул`,
`metal + sharp edge + rigid + handle → возможный инструмент/оружие` (концептуально,
не схемы).

## Материализация

Раскрытие грубого представления в детальное: `стул → структурные компоненты →
отдельные части → геометрия → производственная геометрия`. По возможности
детерминированная: индивидуальные объекты порождаются из `hash(world_seed, путь)`,
в БД записывается только изменённое (идея copy-on-write из `../ideas/WORLD_MODEL_IDEA.md` §5).

## Постоянство

После того как область стала каноном, повторная генерация её не перезаписывает.
Новая генерация заполняет неизвестное.
